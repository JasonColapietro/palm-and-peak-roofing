# Palm & Peak Roofing

A polished website concept for a fictional Palm Beach roofing company.

Live website: https://jasoncolapietro.github.io/palm-and-peak-roofing/

This is a demonstration website. Palm & Peak Roofing is fictional and no roofing services are offered through this site. The architectural hero image was generated for this concept.

## Hosting

GitHub Pages serves the root of the `main` branch. The website is static HTML and CSS with a locally hosted WebP image; no build step, account, or login is required to view it.

## Files

- `index.html`: homepage
- `residential-roofing.html`, `roof-inspections.html`, `storm-restoration.html`: service pages
- `notes/`: build notes (index and three articles) by Suede AI about the concept
- `sitemap.xml`, `llms.txt`: crawler and AI-reader indexes
- `styles.css`: shared responsive styles
- `roofing-home.webp`: hero image
- `.nojekyll`: serves the static files directly
